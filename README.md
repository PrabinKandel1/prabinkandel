# Prabin Kandel — Digital Lab

An experimental portfolio exploring web interfaces, software projects, and browser-based experiences.

This project represents an earlier stage of my web development journey, bringing together personal projects, interactive experiments, and modular portfolio components.

## Project Structure

- `index.html` — Main portfolio page
- `case-studies/` — Case studies for Prometheus X and Hire-Nepal
- `games/` — Browser games and the Interactive Lab hub
- `assets/images/` — Portfolio images and visual assets
- `css/` — Stylesheets for the portfolio and case studies
- `js/` — JavaScript for interactive features and site behavior

## Technologies

- HTML5
- CSS3
- JavaScript

## Contact Configuration

The contact module supports EmailJS when valid account configuration is provided through `js/emailjs-config.js`. Otherwise, it falls back to a `mailto:` contact flow.

No private credentials should be committed to this repository.

## Running Locally

1. Clone or download this repository.
2. Open `index.html` in a browser, or serve the project directory using a local static web server.
3. If using the EmailJS contact feature, configure it with your own valid credentials.

## Deployment

This is a static website and can be hosted on a compatible static hosting service. This repository is maintained as an experimental project and does not need to be deployed.
